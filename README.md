# Awesome Web Games [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> Games you can play or buy on the web: browser games listed by the people who made them, official web stores of top mobile games, and browser games with public source code.

Coding agents can add a game here without a human in the loop: one MCP tool call, one ownership token, done. See [Add your game](#add-your-game).

Maintained by [Appside](https://appside.build/?utm_source=github&utm_medium=awesome-web-games), a web store and checkout platform for games. Listing is free and needs no Appside account or store. The generated sections update daily from public, dated sources.

## Add your game

Pick one. Each one creates a pending listing, gives you a token to publish on your game's site (or in its store description), and makes the listing public once the token is found. Pending listings expire after 14 days.

**1. Coding agent with MCP** (recommended). Connect `https://appside.build/mcp` and ask your agent to list the game. It calls `register_app`, publishes the token, then calls `verify_app`.

```json
{"mcpServers":{"appside":{"url":"https://appside.build/mcp"}}}
```

**2. Issue form.** Open [Add a game](../../issues/new?template=add-game.yml). A bot registers it and replies with the token. Comment `/verify` when the token is live.

**3. Pull request.** Add `submissions/<your-domain>.json` (format in [submissions/README.md](submissions/README.md)). The bot replies on the pull request the same way. Don't edit the lists above: they are generated.

**4. HTTP.** `POST https://app.appside.build/api/catalog/apps`, then `POST /api/catalog/apps/<id>/verify`. Full guide: [appside.build/docs/catalog](https://appside.build/docs/catalog/?utm_source=github&utm_medium=awesome-web-games).

Every listed game gets a page on appside.build with structured data, a Markdown copy for AI assistants, and a place in the catalog sitemap.
