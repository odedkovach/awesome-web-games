# Contributing

- **Your own game:** see [Add your game](README.md#add-your-game). Listings are verified by a token on your domain or store listing, so you can only list games you control.
- **An open-source browser game you like:** add it to `curated.json` in a pull request with a playable HTTPS link and its source repository. A maintainer reviews these by hand.
- **A correction to a mobile game web store:** open an issue with a public source. The store list comes from the [Mobile Game Web Store Index](https://appside.build/index/), which records a source and a check date for every URL.

Generated sections of README.md are overwritten daily; edit `curated.json` or submit through the catalog instead.
